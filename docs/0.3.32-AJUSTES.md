# TrackIA 0.3.32 · ajustes sin entrar a un acompañante

Entrega de la historia US2 del SDD 004. Antes, configurar la IA, la cuenta o la apariencia exigía abrir un
acompañante y buscar en su menú lateral. Ahora el tablero tiene su propio acceso y el chat solo conserva lo que
pertenece a ese acompañante.

## Qué cambia

- **Tablero**: engranaje «Ajustes» en la barra y tarjeta **IA sin conectar** («Conectar») mientras el asistente
  no esté verificado. Se comprueba al abrir, al volver de la configuración y al reanudar la app. Con la IA
  verificada la tarjeta no aparece. («IA sin verificar» y «IA no disponible» usan la misma tarjeta con otro texto.)
- **Pantalla Ajustes** (`lib/ui/settings.dart`), con el estado de cada fila:

  | Sección | Fila | Subtítulo |
  |---|---|---|
  | Asistente | Inteligencia artificial | Verificada · modelo / Sin conectar / Sin verificar |
  | Tus datos | Cuenta y datos | correo del perfil o «Perfil local» |
  | | Exportar e importar | |
  | App | Avisos | Activados / Desactivados |
  | | Apariencia | Automático / Claro / Oscuro |
  | | Ayuda y bienvenida | |

  No hay una fila «Google Sheets»: la conexión con Google se gestiona en «Cuenta y datos» y la hoja de cada
  acompañante en su menú ⋮ (FR-005 enmendado en la especificación).
- **Chat de un acompañante**: sin menú lateral. La barra muestra volver, el icono y el nombre del acompañante
  (al tocarlo se abre un selector para cambiar de acompañante) y un menú ⋮.
  Cambiar de acompañante **sustituye** el chat, así que un solo «Atrás» vuelve al tablero.

## Mapa de menús aplicado

| Antes | Ahora |
|---|---|
| Menú lateral → Acompañantes | Botón «Atrás» |
| Menú lateral → Apariencia | Ajustes → App → Apariencia |
| Menú lateral → Ayuda y bienvenida | Ajustes → App → Ayuda y bienvenida |
| Menú lateral → interruptor de avisos, Probar notificación, Permitir avisos puntuales | Ajustes → App → Avisos |
| Menú lateral → Cuenta y datos | Ajustes → Tus datos → Cuenta y datos |
| Menú lateral y barra → Exportar / importar, Tus datos | Ajustes → Tus datos → Exportar e importar |
| Menú lateral y barra → Configurar IA, Proveedor de IA | Ajustes → Asistente → Inteligencia artificial (y el botón «Configurar IA» del chat sin IA) |
| Menú lateral → Rutinas e historial | Chat → ⋮ → Rutinas e historial |
| Menú lateral y barra → Enviar a Google Sheets | Chat → ⋮ → Enviar a Google Sheets |
| Menú lateral y barra → Archivar chat | Chat → ⋮ → Archivar chat |
| Menú lateral y barra → Chats archivados | Chat → ⋮ → Chats archivados |
| Menú lateral → Hoja cargada | Chat → ⋮ → Hoja cargada |
| Menú lateral → Finalizar día | Chat → ⋮ → Finalizar día (solo GymBro con sesión abierta) |
| Menú lateral → Recuperar preparación | Chat → ⋮ → Recuperar preparación (misma condición) |
| Interruptor «Avisos de actividad y descanso» del panel | «Avisos desactivados · Activar» en el panel, solo si la actividad tiene descanso o duración y los avisos están apagados |

El chat que no está en modo actividad (el de la pantalla antigua `GymHome`) conserva su barra con iconos.

## Evidencia

- Pruebas: `settings_screen_test` (6), `companion_dashboard_test` (17), `menu_map_test` (8: una por fila del mapa),
  `companion_switch_test` (1, extremo a extremo con `GymApp`) y `chat_archiving_test` actualizada al menú ⋮.
- Integración en `emulator-5554` (API 35, `--no-dds`): `transfer_flow_test` y `appearance_android_test`
  pasan el caso con el recorrido nuevo (el runner añade su error de carga habitual).
- Capturas en `docs/screenshots/0.3.32/`: `ajustes-tablero-oscuro.png`, `ajustes-oscuro.png`, `avisos-oscuro.png`,
  `chat-menu-oscuro.png` y `cambiar-acompanante-oscuro.png`.
- Comprobado a mano en el emulador: engranaje → Ajustes → Avisos; GymBro → ⋮ con las cinco acciones; título →
  selector → Calma sustituye el chat y «Atrás» llega al tablero.

## Límites

- Las pruebas de integración `profile_isolation_android_test` y `chat_scroll_android_test` se actualizaron al
  recorrido nuevo pero **no se ejecutaron** en el emulador en esta entrega.
- Tres de las pruebas de integración tocadas (`appearance`, `profile_isolation`, `transfer_flow`) esperaban un
  menú lateral en el tablero que ya no existía desde los acompañantes (0.3.29): estaban rotas antes de este cambio.
- La pantalla Avisos usa su propia instancia de `RestNotificationController` cuando se abre desde Ajustes; el
  chat crea otra al abrirse, así que no comparten estado en memoria.
